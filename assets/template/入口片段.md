# 入口片段

把下面分隔线之间的内容，原样粘贴到你所用 AI 工具的全局入口文件里（位置见 README 的表格）。如果记忆库不在 `~/ai-memory`，先把路径全部替换掉。

---

## 我的 AI 记忆库

我的个人记忆库在 `~/ai-memory`。

1. 每次开工先读 `~/ai-memory/00-索引/AI启动卡.md`，了解我是谁、怎么合作、哪些事不能做。
2. 需要更多背景时，按 `~/ai-memory/00-索引/读取协议.md` 挑一到三篇相关笔记，不要全部读完。
3. 优先级：我当前的指令 > 当前项目里的规则文件 > 记忆库。记忆库和当前指令冲突时，按当前指令做，并告诉我哪里冲突了。
4. 我在对话里表达长期偏好、纠正你的做法或撤销旧要求时，按 `~/ai-memory/00-索引/收件箱.md` 的格式在末尾追加一行，并告诉我已经记下。只追加，不要直接改 `01-用户记忆/`。
5. 不要把密码、API Key、Cookie、Token 等凭据写进记忆库。
