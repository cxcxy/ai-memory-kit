# AI 记忆库模板

让 AI 记住你是谁。接入的 Agent 能读取同一份背景、项目决定和实践经验。是否支持本地文件与入口规则，要按工具实际能力验证。

不需要向量数据库，也不需要写代码。整个记忆库就是一个装着 Markdown 文档的文件夹，用任何文本编辑器或 Obsidian 都能打开。

> 如果你是通过 `ai-memory-kit` Skill 拿到的这个模板，直接对 AI 说“帮我搭一个 AI 记忆库”，下面三步会由它带你完成。本文件是手动搭建时的说明。

## 它解决什么问题

每次新开一个对话，AI 都像第一天来上班的新同事：你是谁、喜欢什么风格、项目做到哪了、哪些东西不能碰，全得重新说一遍。

这个模板做三件事：

1. **读**：AI 开工先读一页“启动卡”，马上知道你是谁、怎么合作。
2. **记**：你确认重要的决定、经验或长期要求时，Skill 保存来源和范围，确认后更新正式页面与启动卡。
3. **整理**：每天或每周整理一次，把反复出现的习惯写进长期记忆，把过时的标记作废。

## 文件夹结构

| 抽屉 | 放什么 | 谁来写 |
|---|---|---|
| `00-索引/` | 启动卡、读取规则、收件箱、同步说明、项目索引 | 你先填启动卡，之后主要由 AI 维护 |
| `01-用户记忆/` | 我是谁、长期偏好、边界与禁区、待确认偏好 | 整理任务按规则写入，你随时可以改 |
| `02-项目/` | 一个项目一页：目标、当前进度、关键决定 | AI 和你一起写 |
| `03-每日记录/` | 每天和 AI 聊了什么、定了什么 | 每日整理任务 |
| `04-每周复盘/` | 每周去重、提升习惯、清理过时内容 | 每周整理任务 |
| `99-原始资料/` | 需要核对时才翻的原始文件 | 你 |

## 今晚就能做的三步

### 第一步：放好文件夹

把整个模板文件夹放到用户目录下，改名为 `ai-memory`，也就是 `~/ai-memory`。

为什么放这里：Mac 的桌面、文稿、下载是隐私保护目录，命令行类 AI 工具访问时会被拦或要授权；iCloud 和网盘的“优化存储”会把文件挪到云端，AI 读到的是空占位。用户目录根下的英文路径没有这些问题。想要版本历史，可以初始化 Git 并保存实际提交，之后才能追踪和回滚对应的变化。

### 第二步：填一页“我是谁”

打开 `00-索引/AI启动卡.md`，把带【】的地方换成你自己的内容。写不满没关系，先写五六条最常交代的，例如：

- 你的身份和在做的事
- 希望 AI 怎么回答（先给结论？要不要解释原因？）
- 你的硬性边界（哪些文件不能动、哪些信息不能上传）

### 第三步：让 AI 开工先读它

打开 [入口片段.md](入口片段.md)，把里面的那段话粘贴到你用的 AI 工具的入口文件里：

| 工具 | 放在哪里 |
|---|---|
| Codex | `~/.codex/AGENTS.md`（对所有项目生效） |
| Claude Code | `~/.claude/CLAUDE.md`（对所有项目生效） |
| WorkBuddy | `~/.workbuddy/RULES.md`（部分版本需要在规则设置里手动选中这个文件） |
| Gemini CLI | `~/.gemini/GEMINI.md` |
| Cursor | 设置里的 Rules（用户规则） |
| 其他 Agent | 只要支持自定义规则或系统提示，就把这段话粘进去 |

同时用好几个工具时，每个工具的入口都粘同一段话，它们就会读同一个记忆库。

做完后，新开对话询问真实项目要求并指出依据，再完成一个小任务；配置文件存在不代表真实读取已经验证。

## 进阶：让它自己整理

手动三步只建立入口；完整的记录、确认和整理流程请使用 ai-memory-kit 的 references/maintenance.md。想让记忆库越用越准，需要定期整理：

- **手动**：每周对 AI 说一次“按 `~/ai-memory/00-索引/同步任务说明.md` 做一次每周复盘”。
- **自动**：如果你的工具支持定时任务（例如 Codex 的自动化、Claude Code 的定时任务），把 [定时任务指令.md](定时任务指令.md) 里的那段话设成每天晚上运行一次。

自动整理会读你本机的对话记录。读之前先确认你的工具会把会话保存在哪里，然后填进 `00-索引/同步任务说明.md` 的“数据来源”表。

## 两条最重要的规矩

1. **读的规矩**：AI 开工不全读，先读启动卡和索引，再按任务挑一到三篇相关笔记。文件越来越多以后，这条能保证它读得又快又准。
2. **写的规矩**：所有要写进去的内容分成四类：事实、决定、偏好、推断。AI 自己猜的只能进“待确认”，不能当成你说的。

## 注意

- **不要把密码、API Key、Cookie、登录凭据写进记忆库。** 模板里的规则已经要求 AI 不写，你自己填的时候也别写。
- 记忆库是本地文件。用网盘或 Git 同步时，确认仓库是私有的。
- 换电脑时，文件夹会跟着同步走，但各个工具里的定时任务不会，要在新电脑上重新设置。
- 记忆库最怕的不是记少了，而是记错了。发现 AI 记错时，直接改对应的笔记，或者告诉它“这条记错了”。
