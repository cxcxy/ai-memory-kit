# 同步任务说明

整理与复盘使用当前 ai-memory-kit 的 references/maintenance.md。用户表达和核对内容，Agent 执行脚本，不要求用户手动整理目录。

## 先处理记录

1. 读取收件箱、待处理记录和已确认索引，列出本次尚未处理的范围。
2. 用户已明确确认的决定与要求可应用；推断、资料提炼和冲突集中核对。
3. 用 record_memory.py 留下项目决定的原因、实践经验的结果与适用条件；用 apply_memory.py 同步更新正式页面、索引和启动卡。
4. 已确认状态作处理回执；保留原记录，不清空整个收件箱。
5. 有新纠正或撤销时立即更新同主题确认摘要，不等周末。

## 原始资料

只读取用户授权的来源。本地记忆优先于扩展会话扫描；网页或数据库不可读就说明缺口，不猜、不上传。

## 多个工具共用

记录与应用脚本原子取得 00-索引/.整理中。占用时等待或稍后重试，不并发更新、不删除其他任务的锁。只在一个工具设置定时整理。

## 定期复盘

检查适用范围、重复主题、撤销和过时内容，更新项目进度。保留用户自写内容和受管理区块。总结结束后运行 apply_memory.py --refresh，让已经确认的要求与启动卡一致。

最后在同步状态记录覆盖日期、处理 ID、受影响页面、未完成项和原因。定时任务不随文件夹自动迁移，换电脑后重新验证。

## 边界

只处理本库、保留来源与历史，不写入凭据。用户最新明确要求与项目规则优先于旧记忆。所有“已完成”都以文件更新和实际验证为依据。
